# MXTA-O Portfolio

A modern, responsive portfolio website showcasing my projects and skills.

## 🌐 Live Demo

Visit the live website at: [https://mxta-o.github.io](https://mxta-o.github.io)

## ✨ Features

- **Responsive Design**: Fully responsive layout that works on all devices
- **Modern UI**: Clean and professional design with smooth animations
- **Easy Navigation**: Smooth scrolling between sections
- **Mobile Menu**: Interactive hamburger menu for mobile devices
- **Sections**:
  - Home (Hero section)
  - About Me
  - My Projects
  - Skills
  - Contact

## 🛠️ Technologies Used

- HTML5
- CSS3 (with CSS Grid and Flexbox)
- Vanilla JavaScript
- No external frameworks or libraries

## 📦 Deployment

This website is automatically deployed to GitHub Pages from the main branch.

## 🚀 Local Development

To run this project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/mxta-o/mxta-o.github.io.git
   ```

2. Navigate to the project directory:
   ```bash
   cd mxta-o.github.io
   ```

3. Open `index.html` in your browser or use a local server:
   ```bash
   python3 -m http.server 8080
   ```

4. Visit `http://localhost:8080` in your browser

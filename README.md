# Portfolio

my personal portfolio built with Astro, Svelte, Three.js, and Tailwind CSS.

## Tech Stack

- **Astro** - Static site generator with Islands Architecture
- **Svelte** - Reactive UI components
- **Three.js** - 3D graphics and animations
- **Threlte** - Svelte bindings for Three.js
- **Tailwind CSS** - Utility-first CSS framework

## For Dev Testing

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Features

- Galaxy inspired minimalistic design
- Immersive (or i intend it to) experience
- Interactive 3D shapes and animations
- Smooth scroll animations
- Responsive design

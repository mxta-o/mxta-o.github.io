# Audio Assets

Put your uploaded audio files in this folder.

Recommended files used by the site right now:
- `ambience.mp3` -> looped background ambience
- `card-render.mp3` -> sound effect when section cards render/activate

Resulting URLs in the app:
- `/audio/ambience.mp3`
- `/audio/card-render.mp3`

Tips:
- Keep ambience relatively quiet and non-intrusive.
- Prefer short SFX clips (<1s) for responsive UI feedback.
- Compressed MP3 files are usually best for web delivery.
